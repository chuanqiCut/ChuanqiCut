# 归档区（只读）

这里放**过期但不得删除**的过程记录。与本仓其余文档的关系由 ADR-0019（文档六层结构）与
ADR-0044（顶层布局）界定。

## 规则

1. **只读。** 归档内容一字不改：状态纠偏写进新的 HANDOFF 或归属模块册，不回来改旧文。
   旧交接文档里写着的"下一步/未完成"是**当时的快照**，照它动手会做错事（发生过：
   HANDOFF-003 把早已完成的子步骤标成下一步）。
2. **不得作为当前状态引用。** 判断现状的入口只有三个：
   `.ai/modules/<模块>.md` 模块册（进度与门禁记录）、`docs/tasks/TASK-BACKLOG.md`（排期）、
   `docs/handoff/`（在位的最近 5 份交接）。
3. **append-only 文件的旧路径保持原样。** 归档文档里提到的路径可能已经搬家
   （`apps/apple/packages/…`、`engine/bindings/swift/…`、`shaders/src/…`）。
   不回填 —— 它们是历史证据，改了就没法对着当时代码核对。新旧对照看 ADR-0044。

## 怎么按编号找回

- 交接文档：`docs/archive/handoff/HANDOFF-<NNN>-<slug>.md`。
  **编号会重号**（HANDOFF-004 两份、HANDOFF-006 三份）—— 重号不合并、不改号，
  靠 slug 区分；发号器只有集成机（ADR-0019 编号纪律），所以重号是双机并发的既有代价。
- 在位窗口：`docs/handoff/` 只保留编号最新的 5 份（2026-10-16 INFRA-035 起）。
  新交接文档写满 6 份时，最旧那份随下一批归档一起移进来。
