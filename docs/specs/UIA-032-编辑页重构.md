## 1. 问题定性（现状证据）

| # | 症状 | 代码证据 | 根因 |
|---|---|---|---|
| 1 | iOS 竖屏 = 桌面三区硬切（预览 60% / 时间线 25% / 属性面板 15% 常驻） | `EditorLayout.swift` `verticalLayout` | 布局范式错位（RESEARCH-004 §2） |
| 2 | 导入素材后预览无画面（含：每次编辑命令后预览停在旧画面） | `MetalPreviewView.sync()` 仅在 **pts 变化** 时向泵请求；`EditorViewModel.applySnapshot`（导入/撤销/移动/裁剪落地）**不触发重渲染请求** —— 同 pts 的旧帧（导入前的空隙黑帧）被反复 blit | 预览活性缺口：渲染触发只有「播放头变了」一条路，没有「模型变了」这条路 |
| 3 | 播放控制是时间线头部一枚 caption 小图标，且无片段时置灰 | `TimelineZone.swift` | 入口弱 + 空状态无引导 |
| 4 | 调试元素直接进 UI（`v37` 快照版本号、素材路径等宽字体列表） | `TimelineZone` / `PropertyPanelZone` | 打磨为零 |
| 5 | 无时间码显示、无点按预览暂停、素材库无常驻入口（藏在右栏/底条 15% 里） | — | 交互惯例缺失 |

症状 2 的机制（修复依据）：导入完成 → 快照回流 → `updateUIView → sync(pts:0)`，`self.pts == pts` 分支不发请求；`draw()` 取到的是布局期对**空时间线**渲染的空隙黑帧（`kIoNotFound` 清屏黑，seq 未变），自驱条件 `frame.pts != pts` 不成立 → 停止追帧。演示钩子（`CQ_DEMO_VIDEO`）把播放头设到 0.5s，掩盖了该缺口 —— 这是它至今没暴露的原因。

## 2. 目标（成功行为）

1. **导入即见画**：导入成功（或任何命令落地）后，预览在当前播放头自动重渲染，无需移动播放头或播放。
2. **剪映形状**：iOS 竖屏 = 预览最大化 + 播放控制条（预览下方）+ 时间线固定条 + 底部工具栏 + 媒体抽屉（bottom sheet）；无常驻属性侧栏。
3. **点按预览 = 播放/暂停**（行业惯例，RESEARCH-004 §6.2 点 4）。
4. **空状态有引导**：无片段时预览区给出「导入素材开始创作」提示与主操作入口，播放钮置灰语义不变。
5. **调试元素退场**：`v\(version)` 等移入 `#if DEBUG`；素材路径细节只在媒体抽屉内呈现。

## 3. 非目标（防膨胀）

- 不做：时间线缩略图/波形（归 §12 时间线缩略图任务）、macOS 惯例化（另行立项）、面板框架全量迁移（UIA-019）、属性参数面板（UIA-006，内核 MODEL-003/COLOR-003 未落地）、导出（EXPORT-001）、片段级变换（MODEL-003）、双指缩放时间线与拖拽调高（登记 BACKLOG）。
- 不引第三方 UI 库（RESEARCH-004 §3.3/§6.5 论证）。
- 不动 Command/Undo 线程模型（ADR-0012）、不动内核与绑定层（零 ABI 变更）。
- 不做浅色主题（深色唯一）。

## 4. 方案

### 4.1 UIA-020：预览活性修复（先行，独立可验收）

1. `EditorViewModel`：新增 `@Published private(set) var renderEpoch: UInt64`；`applySnapshot`（含 `refreshTimeline` 的初始装载）末尾对当前 `playhead` 补一次 `previewPump?.request(pts:)` 并 `renderEpoch += 1`。语义：**模型每次推进 = 该时刻画面可能失效 = 请求重渲染**。
2. `PreviewMTKView.sync`：新增 `renderEpoch` 入参；epoch 变化 → `pump.request(pts:)` + 装载追帧。追帧停止条件由 `frame.pts != pts` 改为 **seq 判定**：装载时记录当时最新帧 `seq`（经 `withLatestFrame` 读一次），`draw()` 中 `frame.seq != seqAtArm` 即认为请求的帧已上屏、停止追帧（上限保留 90 次）。
   - 覆盖旧语义：pts 变化路径同样走 seq 判定（旧 pts 比较在「同 pts 重渲染」下永不收敛，正是症状 2）。
   - 空隙/渲染失败：泵按既有语义发布（黑帧/nil 纹理，seq 前进）→ 追帧正常收敛，行为与「空隙=黑」契约一致。
3. 失败可见性：`draw()` 命中 nil 纹理时保持清黑，但 `EditorViewModel` 暴露 `lastPreviewStatus`（os.Logger 记录 nonOk 计数变化）—— 本期只做日志与 DEBUG 标注，不弹错误 UI（避免与降级展示混叠，开放问题 §7-3）。

### 4.2 UIA-032：iOS 剪辑页布局（`EditorLayout.swift` iOS 分支重写）

```
竖屏（compact）
┌─────────────────────────┐
│ 预览区（弹性占满剩余）    │ 点按 = 播放/暂停；空态引导视图
├─────────────────────────┤
│ ▶/⏸  00:03.2 / 00:12.0 │ TransportBar：播放钮 + 时间码
├─────────────────────────┤
│ 时间线（固定 140pt）      │ EditorTimelineView 原样嵌入
├─────────────────────────┤
│ ↩︎ ↪︎ ｜ 媒体 音频 文字 特效 │ BottomToolbar：撤销/重做 + 一级工具位
└─────────────────────────┘   未实现工具置灰 + 「后续任务」语义标注
横屏（regular）：沿用现 macOS 同构布局（macOS 惯例化另行立项）
```

- `EditorView` 重排为上述结构；`PropertyPanelZone` 拆解：素材库（导入双入口 + 列表 + 失效标记）迁入**媒体抽屉**（`MediaSheet.swift`，detents medium/large，UIA-013 同款半屏）；属性占位区随 UIA-006 取消。
- 时间码：`mm:ss.d` 当前播放头 / 时间线总时长（`session.timelineDuration()`，有理数换算在 ViewModel，红线 #4）。
- 顶栏（iOS）：关闭（返回首页，导航弹出）+ 导出主按钮（**置灰**，标注「导出能力未就绪」——EXPORT-001 未做，诚实降级）。
- 底部工具栏「媒体」常驻入口 → 打开媒体抽屉；音频/文字/特效 = 置灰占位（`disabled` + help 文案），入口形状先立住。
- Theme 扩展（增量，不做全量清扫）：`transportBackground`、`toolbarBackground`、`accent`（与时间线片段蓝同族）、间距/圆角常量按 RESEARCH-004 §6.0 阶梯命名；全量令牌清扫仍归 UIA-033。
- 摇一摇撤销继续不做（既有约定）；macOS 快捷键行为不变（`EditorLayout` 平台差异收敛原则不动）。

## 6. 约束对照（架构红线）

红线 #1（业务下沉 C++）：本 Spec 纯视图层 + ViewModel 触发时机，无业务逻辑进 Swift —— 播放头/时间码换算用既有绑定（有理数）。#4（有理数时间）：时间码显示在 UI 层格式化，存储/传递全程 RationalTime。#5（UI 不改模型）：新增交互（点按暂停）走既有 `togglePlayback()`。#8（主线程零阻塞）：媒体抽屉复用 UIA-012/013 批量链路（条间 yield）。#3（能力运行时查询）：导出置灰依据 EXPORT 能力缺失（常量 + `#if DEBUG` 标注，能力位接入归 EXPORT-001）。

## 7. 开放问题（不悄悄假设）

1. **真机症状归一**：模拟器（Intel，iOS 18.4）已复现「启动/首页/进编辑器」链路，但相册导入（PHAsset→tmp→importMedia）与 iPhone 实拍 HEVC/HDR 10-bit 解码需真机验证 —— 若真机导入后时间线**有**片段，症状 2 即为主因；若**无**片段，需补查相册落盘/探测链路（传哲真机走查 UIA-032 交付时一并确认）。
2. 导出按钮：置灰展示 or 隐藏？（本期：置灰 + 标注，Export 立项后启用。）
3. 渲染失败（如素材解码不支持）是否需要显式错误 UI？（本期：黑帧 + 日志；与 preview 层「诚实降级」契约对齐，错误 UI 另立任务。）
4. 「音频/文字/特效」占位位的最终清单与顺序，待 UIA-019 面板框架立项时定。

## 8. 跨端

- Android/鸿蒙不在本轮（P1/P2，届时按对应平台惯例重做，共享的只有状态与命令链路）。
