## 拍摄闪退（真机 iPhone 17 Pro）：MultiCamSession 不支持 sessionPreset

- 现象：进相机页即崩 —— `NSInvalidArgumentException: -[AVCaptureMultiCamSession
  setSessionPreset:] AVCaptureSessionPreset1920x1080 is not a supported preset`。
- 根因：`CameraManager.makeSession()` 在 `isMultiCamSupported` 为真时**恒建**
  `AVCaptureMultiCamSession`（iPhone 15/17 恒 true = 默认路径），而 `configureLocked` 与
  `setCaptureQuality` 无条件 `session.sessionPreset = ...`。multiCam 子类**运行时拒绝** preset
  （`canSetSessionPreset` 拦不住，是抛 NSException 不是返回 false）。
- 修法（Apple 口径：multi-cam 逐设备设 activeFormat）：
  1. 新增 `isMultiCamSession` 分流 + `applyCaptureQualityLocked(_:)`：multiCam 走
     `applyFormatLocked(_:to:)`（在覆盖当前 fps 的候选 format 里取分辨率最接近档位目标的一个），
     普通 Session 仍走 `canSetSessionPreset` → `sessionPreset`。
  2. `CaptureQuality` 加 `targetDimensions`（720/1080/4K 目标尺寸，供筛选用）。
  3. `addVideoInputLocked` 里 multiCam 新建 input 也要重放档位 + 帧率（换 format 会重置帧率范围）。
  4. 不支持/无候选时 Warn 日志 + 保持原档位 + 回调 false（诚实降级，不伪造成功）。
- 验证：CameraManager `swiftc -typecheck`（device SDK, Swift 6）零错零警；iOS 壳
  `-scheme ChuanqiCutApp`（device SDK）重编结果见本条末尾。**真机复验待传哲**（相机实现层
  iOS 专属，编译过 ≠ 能跑；门禁 PASS=14 全绿之后真机一开就崩就是教训）。
- 落账：pitfalls **P93**；camera.md 模块册待补。

### 启动白屏根因（重要坑）
- 现象：启动屏是「白板」，不是我们生成的 teal+胶片图标。
- 排查：Info.plist 已正确指向 `LaunchBackground`+`LaunchIcon`，两资源内容也正确（LaunchIcon 720×720、74% 不透明、均值 RGB(51,59,47)；LaunchBackground 深青）。
- 根因：`apps/apple/ios/project.yml` 的 `UILaunchScreen: {}` 是**空字典**。该工程由 XcodeGen 从 project.yml 生成 pbxproj/Info.plist（project.yml 注释明写「plist 由本文件生成，不存手工副本」）。空 dict → xcodegen 生成 `<key>UILaunchScreen</key><dict/>`（无底色无图）→ 白板启动屏，覆盖掉之前手改的 Info.plist。
- 修复（耐久，改真源）：
  1. `project.yml` `UILaunchScreen: {}` → `UILaunchScreen: { UIColorName: LaunchBackground, UIImageName: LaunchIcon }`。
  2. 跑 `/usr/local/bin/xcodegen generate`（apps/apple/ios）重新生成；生成的 Info.plist 启动屏正确；`AppIcon.appiconset/Contents.json` 被 xcodegen 原样保留（10 尺寸+1024 未丢）。
- 结论：iOS 工程的 Info.plist 一律以 project.yml 为准，**不要再手改 Info.plist**；任何 plist 键要加就加进 project.yml 的 `info.properties`，再 xcodegen 生成。
- 待验：真机/模拟器跑一次确认启动屏不再是白板（属门禁/真机，按约定集成机执行前须先问传哲）。本机非集成机、无 CocoaPods。
