## 1. 背景与根因

### 1.1 磨皮闪烁（CAM-015）

CAM-012 的 σr 参数在宿主 GPU harness 上用**未标记 BGRA**定标，代码注释明确
"表现为 gamma 域"（BeautyKernel.swift:41-44）。但真机链路：

```
CIContext(mtlDevice:)            ← 无 options（CameraViewModel.swift:74）
  → workingColorSpace 默认 = 线性
相机 BGRA 帧（带色彩标记）→ CI 色彩匹配到线性域 → kernel 采样到线性亮度
```

同一 σr（0.03~0.11）从 gamma 域搬到线性域：高光区（皮肤）边缘亮度差放大约
1.5~2 倍 [E] → 双边权重塌陷 → 保边失效 + 传感器噪声逐帧穿透 → 皮肤区域
逐帧沸腾/闪烁。TASK-CAM-012 剩余风险栏已预判（"若真机上 CI 工作空间表现
不同……"），且真机视觉验收本就未做。

### 1.2 录制与预览颜色不一致（CAM-015，顺带发现）

`CameraRecorder.appendVideo` 把 CI 渲染结果写入适配器池缓冲（32BGRA，无色彩
空间标记），线性域数值按未标记写出 → 预览（线性→deviceRGB 输出转换）与
录制产物颜色不一致 [hypothesis，真机复核]。

### 1.3 美白/磨皮不基于人脸（CAM-016）

`CameraBeauty.apply` 对整帧做曝光/亮度（CameraBeauty.swift:94-104）与全帧磨皮，
背景墙面一起处理。CAM-011 已建好检测桥（VisionDetector + One-Euro 关键点平滑 +
Vision→图像归一化坐标契约），美颜链尚未消费。

## 2. 目标

1. **磨皮不闪**：CIContext 显式 `workingColorSpace = gamma sRGB`，使真机 kernel
   输入域与 harness 定标域一致；真机人工验收闪烁消失、保边恢复。
2. **预览=录制**：录制路径 buffer 显式标记色彩空间，渲染输出显式 sRGB。
3. **美白/磨皮只作用于人脸**：接 CAM-011 检测桥 → 人脸框（帧间平滑）→ 羽化
   蒙版 → 磨皮与美白经蒙版混合；背景不受影响。
4. **引擎可观察**：磨皮引擎激活/回落状态一次性日志（修"引擎是否在跑"不可知）。

## 3. 非目标（明确不做）

- 美型（瘦脸/大眼/下巴）——CAM-013 范围不变，本卡不触碰其写集。
- 双边滤波 kernel 本体改动（权重/采样/两 pass 结构不动；蒙版在 kernel 之外
  以 `CIBlendWithMask` 施加，SharedUI 纯函数可测）。
- 皮肤分割级精细蒙版 / landmark 级肤色区域——v1 用人脸框羽化椭圆。
- Android / 鸿蒙（相机模块 iOS 专属，ADR-0014；SharedUI 纯函数保持平台无关）。
- 磨皮耗时优化（≤8ms 真机指标仍归 CAM-012 遗留待办）。
- macOS 相机（不存在该能力，SharedUI 默认实现路径 `faces=nil` 保持旧行为）。

## 4. 行为契约（CAM-016 核心）

```swift
// CameraBeautyParams
func apply(to image: CIImage, faces: [CGRect]?) -> CIImage
```

| 输入 | 行为 | 依据 |
|---|---|---|
| `faces == nil` | 全画面（旧行为） | 能力缺失降级：macOS/未接检测方兜底，公开语义向后兼容 |
| `faces == []` | **直通（美颜整体不生效）** | 对齐 CAM-013 美型"无脸直通"既有验收口径 |
| `faces` 非空 | 生成羽化蒙版 → 磨皮/美白蒙版混合 | 用户价值本体 |

- 人脸框数据流：采集帧（每 N 帧，默认 N=3 [E]）→ VisionDetector →
  `visionRectToImageNormalized` → box 两角点复用 `smoothKeypoints` 帧间平滑
  （dropout 保持上帧 = 检测跳帧不抖动）→ 线程安全 store → 预览/拍照/录制三路同源。
- 坐标链：Vision(origin 左下) → 图像归一化(origin 左上, CAM-011 契约) →
  CI 空间(origin 左下) 翻转映射——纯函数 + 单测锁定。
- 引擎注入签名 `(CIImage, Double) -> CIImage?` **不变**；蒙版在 `CameraBeauty.apply`
  内统一施加（kernel 与默认 CI 实现都先出全帧结果，再混合）。
