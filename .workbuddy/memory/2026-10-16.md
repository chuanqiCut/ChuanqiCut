## #21 旋转修复（GPU blit UV 旋转，回退 Core Image 解码旋转）

- 根因：此前在解码阶段用 Core Image 对像素旋转，触发无标签 BGRA 缓冲的色彩空间转换 → 色偏。
  用户要求改到 GPU 层（blit 的 UV 旋转），不动色彩空间。
- 改动链路（11 文件）：decode 仅下发 `rotation` 元数据（不旋转像素）→ preview `Acquire(out_rotation)`
  → `ChqRenderNodeDesc.source_rotation`（Prepare 回填）→ evaluator Encode 用旋转后尺寸算视口 +
  把 rotation 传给 `ChqIBlitPass::Encode` → blit 在共享顶点缓冲重烤 UV（`RotateUv`/`BakeRotation`）。
- 编译期抓到并修复**截断 bug**：旋转角全程用 `uint8_t` 存，270>255 → `static_cast<uint8_t>(270)=14`，
  会静默丢失 270° 源（iPad 竖屏）的旋转。把 `ChqVideoFrame.rotation` / `rotation_deg_` /
  `source_rotation` / `last_import_rotation_` / `cached_rotation_` / `frame_rotation` / `src_rotation`
  / `DeriveRotationDeg` 返回值 / blit `RotateUv`·`BakeRotation` 形参 / evaluator 局部 `rot` 全部改 `uint16_t`。
- iOS + macOS 双壳构建均 **BUILD SUCCEEDED，0 错误，无新增 warning**。
- 真机复验：传哲已同意并装机。devicectl install 成功（bundleID com.chuanqi.cut），foreground launch
  （CQ_AUTO_ROUTE=editor + CQ_DEBUG_OVERLAY=1）已就绪。**待传哲真机填写问卷（5 项：竖屏朝向正确+
  色彩无偏、滑动流畅、缩略图清晰、绿字帧率、音频回归）；问卷回收前不标记 #21 完成**。
  注：当前工作树含 TimelineKit 迁移 WIP，一并打进包；若崩溃需带 --console 重启动取证。
- **真机首轮反馈：画面倒立（旋转方向反 180°）**。根因：blit 把显示旋转角 R 直接传给 RotateUv，
