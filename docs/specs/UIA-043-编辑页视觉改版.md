## 2. 目标（成功行为）

1. **单色系**：编辑页只有黑 / 白 / 灰，蓝色 accent 在本页退场；主操作 = **白底黑字**。
2. **顶栏**：系统返回钮（左，**不改系统返回样式**）+ 「导出」主按钮位（右，**置灰**，`#if DEBUG` 标注 EXPORT-001 未就绪）。
3. **传输条**：`撤销 · 重做`（左）｜ `播放/暂停`（**水平居中**）｜ `时间码`（右）—— 传哲 2026-10-15 拍板。
4. **底栏**：高度 84pt，6 个工具位等宽铺满（撤销/重做已迁出），图标 22pt、标签 10pt，纯白/灰。
5. **空态**：去掉卡片容器，图标 + 文案 + 白色胶囊按钮直接居中于预览区。
6. **空时间线**：无片段时不画刻度尺与播放头，区域保留（避免布局跳动）。

## 3. 非目标（防膨胀）

- 不做：图标重绘（继续 SF Symbols）、macOS 端视觉改版（另行立项）、首页/相机页改版、时间线缩略图、面板框架（UIA-019）、导出能力（EXPORT-001）。
- 不引第三方 UI 库；不改 `SharedUI/Theme`（跨包，见 §5）。
- 不动命令链路：`undo/redo` 仍走 `EditorViewModel.undo/redo + refreshFromKernel`；`togglePlayback` 语义不变。
- **不动交互**：本批纯视觉，任何按钮的行为、命中区、抽屉开合逻辑保持现状。

### 4.2 分域色表（新增 `EditorChromePalette.swift`）

沿用 `TimelinePalette` 的**分域色表**做法（UIA-041 先例）：色值只服务编辑页，不进 `SharedUI/Theme`，
避免跨包写集冲突（ADR-0034 硬约束）。约定：本文件不 import UIKit/SwiftUI 存储色值（只出 `CGColor`/`UIColor` 转换），
与 `TimelinePalette.RGBA` 同构。

| 令牌 | 值 | 用途 |
|---|---|---|
| `chromeBackground` | #0A0A0B | 传输条 / 时间线 / 底栏统一底色（**三区连成一体**） |
| `chromeHairline` | #1E1E22 α1 | 底栏顶部 0.5pt 分隔线（唯一的分隔手段，不用底色差） |
| `chromeGlyph` | 白 α1 | 工具位 / 播放 / 撤销可用态图标 |
| `chromeGlyphDisabled` | 白 α0.28 | 禁用态图标与标签 |
| `chromeLabel` | #CFCFD4 | 工具位标签 |
| `chromeLabelDisabled` | 白 α0.28 | 禁用态标签 |
| `chromePrimaryFill` | 白 α1 | 空态主按钮底 / 导出可用态底 |
| `chromePrimaryText` | #111111 | 空态主按钮字 / 导出可用态字 |
| `chromeDisabledFill` | #2C2C30 | 导出置灰底 |

## 5. 为什么不动 `SharedUI/Theme`

`Theme` 是多端共享基座（iOS/Mac 多个消费者），改它是**跨包改动**，超出本批写集。
`Theme.accent`（蓝）在**首页/其他页面**继续有效，本批只在**编辑页**停用——即「分域停用一个共享令牌」，
与 UIA-041 建立 `TimelinePalette` 时「播放头在轨道区是白的、`Theme.playhead` 红的继续被别处消费」同一手法。
Theme 的整体收敛仍归 UIA-033，届时整表迁移（含本文件）。

## 8. 开放问题（不悄悄假设）

1. **传输条布局的两种读法**（传哲原话「撤销重做跟播放和时间放一栏」「播放按钮放那栏中间」）：
   本文按 **左：撤销+重做 ｜ 中：播放（水平居中）｜ 右：时间码** 落地；另一种读法是
   `撤销 ▶ 重做`（播放夹在两者中间，时间码另找位置）。**待传哲确认后开工。**
2. **导出置灰 vs 隐藏**：传哲 2026-10-15 拍板「本期显示（置灰）」，沿用 UIA-032 §7-2 的诚实降级口径。
3. **空时间线区域**：保留 140pt 空位（布局不跳）还是折叠为 0（预览更大）？本文取**保留**——对标 App 编辑器恒定有时间线。
4. UIA-042 红色预览选中框与本批单色系是否冲突：红框是**选中语义色**（对标 App 同款），保留不动。

### ⚠️ 工具坑（本次实测）

本机 **BSD grep 不支持 BRE 的 `\|` 转义**，`grep -rn "a\|b"` 会静默零命中 ——
