## HomeView 编译不过的排障（诊断，未落盘修复）

**根因链（两层）**

1. **Xcode 工程产物陈旧**（主因）：`apps/apple/ios/ChuanqiCut.xcodeproj/project.pbxproj`
   只引用 `ChuanqiCutApp.swift`，`LastUpgradeCheck = 1430`（≈ Xcode 14.3 时代生成），
   HomeView.swift 与 Camera/ 全部（10 .swift + 1 .metal）从未进过编译。
   表现：`ChuanqiCutApp.swift:23: cannot find 'HomeView' in scope`。
   → 已用脚本补齐 12 个文件引用 + Camera/Detection/Effects 三个 group（**本地产物，不入库**）。
2. **并行会话 WIP 引入的 C++ 错误**：`core/src/gfx/gfx_device.cpp:183` 用
   `StatusCode::kResource`，枚举里真实名字是 `kResourceExhausted`（5000，status.h:72）。
   隔离编译验证：改成 `kResourceExhausted` 后该 TU 通过（clang++ -c，EXIT=0）。
   **未改仓库** —— 该文件在并行会话的写集里。

**覆盖率事实**
- 修补前 iOSApp 源码进工程比例 1/12（8%）；修补后 12/12。
- 11 个 Swift 文件 `swiftc -parse` 全绿（仅语法，不含类型/符号检查）。
- iOSApp target 的 Swift **仍未真正编译过**：ChuanqiCut pod 的 C++ 先失败，编不到 App target。

**治理缺口（需传哲拍板）**
- pbxproj/xcworkspace 不入库 + 本机**没有 brew / xcodegen / mint** →
  clone 后无法按 project.yml 重新生成工程。要么装 xcodegen，要么把生成产物入库（二选一）。
- 我的 pbxproj 修补只在本机有效，下次 xcodegen 或换机即丢。

**环境**：本机 Xcode 26.6 / macOS 26.7.1（与 MEMORY 里记的 15.4、13.7 都不同 —— 第三台机器）。
