## 1. 对标矩阵（能力级）

| 能力 | 本项目现状 | 抖音/剪映（字节，自研特效中台） | Instagram（Meta） | 差距判定 |
|---|---|---|---|---|
| 磨皮 | 双边 kernel + 脸框蒙版（012/019），细节无回注 | 皮肤分割域 + 高低频分层 + 唇齿眉眼保护，观感「磨而不糊」 | 同级 | **中**：算法骨架对，缺语义保护与细节回注 |
| 美白 | CI 曝光/亮度 + 脸框蒙版 | 肤色域自适应 + 立体高光（骨骼光影） | 同级 | **中**：tone-filter 级，无肤色域/光影 |
| 美型 | 关键点位移场 warp（013，76 点） | 网格 warp + 脸型模板 + 光影绘制（鼻影/卧蚕） | 同级 | **中**：底座 76 点精度不足（主流 240~468 点 [E]） |
| 美体 | 姿态驱动瘦腰/长腿（025 起步） | 全身形变 + 头身比模板 | 少 | **小**：起步方向一致，深度差距靠迭代 |

## 2. 差距定位：五个根因（按杠杆排序）

1. **人像理解底座（最大杠杆）**：主流全部效果建立在「稠密人脸网格（240/468 点级）+
   皮肤/头发/五官语义分割」之上。我们的磨皮波及发丝眉毛、美妆无从谈起、美型精度封顶，
   全部是同一根因。→ CAM-027（分割）/ CAM-028（网格）。
2. **算法质量层**：磨皮缺细节回注（高频回注）与唇齿保护 →「磨皮=糊」观感；美白是
   tone-filter 级。这是参数与 pass 结构问题，底座就位前即可做一半。→ CAM-029。
3. **跟踪稳定性**：15Hz 检测 + 平滑 vs 30-60Hz + 预测——表现为贴纸/美型「慢半拍、
   转头丢锚」。→ CAM-028（检测提频 + 位姿预测插值）。
4. **资产与组合**：妆容包/道具包/组合特效的**资产生产管线**（设计→参数化→清单→许可）
   是字节/Meta 的护城河，算法只是入口。→ 026/014 的资产清单 + 生产管线（另立专项）。
5. **性能预算**：主流全链（磨皮+美型+美妆+贴纸）单帧 GPU ≤5ms 级 [E]（剪映磨皮
   ~2ms [E] 传闻，baselines 已录）。我们单磨皮 9.85ms（宿主）已超预算 → 必须
   pass 融合 + 半分辨率 + MetalFX（022 已落地）。

## 3. 追平路线（三阶段，自研打底为既定拍板）

**阶段一（当前栈内，底座未动）**：
- CAM-029：细节回注 + 唇齿保护 + 肤色自适应 σr（pass 融合，不加预算）；
- CAM-018/019 修复轮已就位的算法驱动语义（nil→直通）全量落实；
- 检测提频 15→30Hz [E] + 平滑参数真机标定（011 内，无新卡）；
- 贴纸/妆容**资产生产管线**立项（设计侧协同）。

**阶段二（底座）**：
- CAM-027 人像分割（Vision 系统能力免费起步：人像 iOS15/头发 iOS17 + 肤色域 [E]）；
- CAM-026 美妆（关键点区域着色 → 分割精修）；
- CAM-023 景深人像（复用 027 分割可大幅简化）。

**阶段三（对齐主流）**：
- CAM-028 ARKit 网格/跟踪升级（1220 点 + 预测插值）；
- 468 点稠密网格（MediaPipe→CoreML 直转，ADR-0005 路线，另卡）；
- 组合特效道具框架（LUT+形变+贴纸打包语义）。

## 5. 决策点（拍板项）

1. **自研 vs 授权**：SPEC §8 Q1 已拍板自研打底；若美妆/分割自研周期超预期，商汤/
   虹软/相芯授权可作过渡（成本/水印/数据合规是代价，走 cq-dependency-governance）。
2. **468 点来源**：MediaPipe 直转（跨端可移植，Android 复用）vs ARKit 网格（iOS 独占
   但零集成成本）——建议双轨：前摄 ARKit、后摄/跨端 MediaPipe。
3. **资产生产**：自建设计管线 vs 外包/采购模板——影响阶段二排期。
