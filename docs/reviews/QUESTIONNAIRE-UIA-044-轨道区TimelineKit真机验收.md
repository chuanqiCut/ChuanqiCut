# 真机问卷 · UIA-044 轨道区接入 TimelineKit

- **日期**：2026-10-15
- **设备**：iPhone 17 Pro / iPhone18,1 / iOS 26.6.1（**Debug** 构建，Intel Mac 编译）
- **被测版本**：本机已安装的最新 Debug App（含 `EditorTimelineKitView` + `TimelineKitAdapter`）
- **ADR**：ADR-0042；**任务卡**：TASK-UIA-044

## 怎么打开

App 已装在设备上。两种看法：

1. 直接点图标 → 首页 → 「编辑器」（此时是空时间线，需从素材库导入）；
2. 用素材自动装载（推荐，省一次导入）：
   ```sh
   xcrun devicectl device process launch --device 0FA3CFBB-50FB-541F-971B-7FF65F5ED9A7 \
     --terminate-existing -e '{"CQ_AUTO_ROUTE":"editor","CQ_DEMO_VIDEO":"cq_demo.mp4","CQ_DEMO_SECONDS":"8"}' \
     com.chuanqi.cut
   ```
   （`cq_demo.mp4` 已推到 App 的 Documents；真机无法脚本点按，只能靠这些环境变量入口。）

## 已知边界（不必当 bug 报）

- 转场 / 关键帧 / 画布 item / 蒙版**本轮不映射**（TimelineKit 有 UI，内核暂无对应命令）。
- iPad 横屏与 macOS 仍是旧 SwiftUI 轨道区（TimelineKit 是 UIKit-only）。
- 素材时长未透传 → 裁剪上限退化为片段自身源区间（不做假限制）。
- 提交后内核若拒绝，会有一次瞬时"弹回"再落到真值（与旧轨道区同源，看是否可接受）。
