## 1. 这批改了什么

| 文件 | 变更 |
|---|---|
| `EditorChromePalette.swift`（新增） | 编辑页分域单色色表 + 尺寸阶梯（底栏 84 / 图标 22 / 传输条 44 / 时间线 140） |
| `UIKit/EditorTransportBarView` | 撤销/重做迁入（原本在底栏）+ 播放水平居中（去掉灰圆底）+ 时间码右；底色统一 |
| `UIKit/EditorToolbarUIView` | 撤销/重做与 spacer 移除 → 6 工具位等宽铺满；84pt；图标 22 / 标签 10；单色 |
| `UIKit/EditorViewController` | 高度改读 `EditorChrome`；空态**去掉悬浮卡片**改白底黑字胶囊；撤销/重做出口改挂传输条 |
| `UIKit/EditorTimelineUIView` | 新增 `setEmpty(_:)`：**空时间线不画刻度尺与播放头**（区域高度保留） |
| `EditorScreen` | iOS 顶栏「导出」置灰按钮位（`.navigationBarTrailing`，iOS 16 API） |

**没改**：命令链路（undo/redo/playback 仍走原 VM 方法）、`TimelineLayout` 纯函数、内核与 ABI、
`SharedUI/Theme`（跨包未动）、macOS 布局分支。

### A. 视觉改版（UIA-043）

| # | 操作 / 期望 | 实际 |
|---|---|---|
| A1 | 进编辑页（空时间线）：预览区中央是图标 + 「导入素材开始创作」 + **白底黑字**胶囊「打开素材库」；**没有**半透明卡片、没有蓝色按钮 | |
| A2 | 传输条：**左** 撤销·重做（无可撤销时两个都暗）、**正中** 播放钮（白色▶，无圆底）、**右** 时间码 `00:00.0 / 00:00.0` | |
| A3 | 底栏：6 个工具位（媒体/画中画/音频/文字/特效/比例）**等宽铺满**，图标明显变大；**没有**撤销/重做，也没有中间空洞 | |
