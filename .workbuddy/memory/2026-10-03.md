选型说明：BACKLOG 里 UIA-005 = 拖拽/裁剪（依赖 UIA-004 + MODEL-002），而 MODEL-002

### 交付（提交见 git log）
- `core/include/cq/command/command.h` + `core/src/command/command.cpp`：
  ICommand（Do/Undo/Redo/Name）+ CommandHistory（线性历史）+ 6 命令
  （AddTrack/RemoveTrack/InsertClip/RemoveClip/MoveClip/TrimClip）
- Timeline 最小扩展：`RestoreTrack/RestoreClip`（显式 id 恢复，next_id_ 保持单调）
- `tests/unit/test_model_command.cpp`（4 组用例）+ CMake 接入

### 关键设计决策
1. **Redo 不能重放 Add/Insert**（会分配新 id，历史里后续命令引用悬空）→
   ICommand 增加 `Redo()` 虚函数（默认重放 Do），结构类命令覆写为 RestoreX 原.id 恢复。
2. 「不存数据拷贝」约束的边界解释：编辑类存增量（id+old/new）；结构类只允许持有
   **单个受影响实体**的内容（回放依据），模型级快照禁止。已写进 command.h 头注释与
   model.md。
3. 失败语义三件套：失败 Execute 不入栈 / 模型不变 / redo 分支保留。
   依赖「命令失败不改模型」不变量（先校验后变更，测试守卫）。

### 验证
- 门禁 **Debug 35/35、Release 35/35**（新增 model_command：0.31s / 0.22s）
- 验收逐条过：201 深度全撤销回初始态（指纹逐字段）→ 全重做回最终态；失败不入历史；
  原 id 恢复；RemoveTrack 撤销恢复轨道+片段；排序不变量稳定
