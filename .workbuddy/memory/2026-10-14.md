## 真机 SIGSEGV 定位与修复（连接传哲 iPhone 17 Pro 联调，22:00-22:15）

- **结论：不是卡死，是必现 SIGSEGV**。根因 `EditorTimelineUIView.swift` 的
  `TimelineContentView.rebuild` 里 `layer.sublayers?.forEach { $0.removeFromSuperlayer() }`
  —— 全清的是 UIView 的 backing layer，**把子视图（主轨「+」按钮）的 layer 一起拔了**；
  UIKit `subviews` 仍持有该 view 而 layer 已离树 → CA 首次提交事务走到
  `_parentTraitEnvironment → superview → CALayerGetSuperlayer` 解引用野指针崩。
- **二分证据（真机 6+ 组对照）**：摘时间线视图不崩 / 摘 addButton 不崩 / 不 rebuild 不崩 /
  裸 UIView 顶替按钮照崩（证明非按钮特有）。退回 HEAD（UIA-042 前）**同样崩** → 与今天的
  SnapKit 迁移无关，是更早的存量缺陷。
- **修复（治本）**：`TimelineContentView` 新增专用自绘容器层 `canvasLayer`
  （init 挂 `layer.addSublayer`、`layoutSubviews` 内 `frame = bounds`），自绘层 9 处全改挂它，
  清空只清 `canvasLayer.sublayers`。子视图层永不被触碰。
- **验证（真机 iPhone 17 Pro，iOS 26.6.1，DEBUG 包）**：push 路径（新增
  `CQ_AUTO_PUSH_EDITOR=1` 自动入口）与 `CQ_AUTO_ROUTE=editor` 各跑 25s，**零 crash、
  零约束冲突**；iOS/macOS 双端壳 **BUILD SUCCEEDED**。
- **新工具（保留）**：`iOSApp/DebugCrashDumper.swift`（DEBUG 信号处理器 → stderr 回溯，
  因为 devicectl 启动的崩溃不落 .ips、lldb device attach 取不到栈）；
  `HomeView` 的 `CQ_AUTO_PUSH_EDITOR=1`（无手点自动复现 push 转场）。
- **坑册**：P131（backing layer 全清 → SIGSEGV）、P132（真机崩溃两条取证通道失效 +
  atos 符号化配方）。台账 `LEDGER-W42` 补记八。
- **待办**：时间线视觉需传哲目检（canvasLayer 改动后图层位置/层级），已追加进
  QUESTIONNAIRE-UIA-042。
