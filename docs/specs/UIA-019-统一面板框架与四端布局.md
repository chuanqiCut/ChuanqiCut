# SPEC-UIA-019：统一面板框架与四端布局

> 版本：v1.0（2026-10-04）
> 调研依据：**RESEARCH-005**（面板级 IA 与四端布局，本文是其技术落地）、RESEARCH-004（页面级范式与视觉基线，本文继承）
> 架构边界：**不新增 ADR**——本文是 ui-apple.md「平台差异收敛在 EditorLayout」、ARCH-005「共享会话状态与组件值不共享 UI」、ADR-0012「交互期不提交命令」的顺势延伸，理由见 RESEARCH-005 §7.2
> 状态：提案（立项后转 TASK-UIA-019）

## 1. 背景与目标

**现状**（RESEARCH-005 §2）：面板开关靠 View 内散落 `@State` 布尔，三种呈现范式（sheet / 常驻条 / overlay）并存无状态机；滑杆、滤镜条每个面板各写一套；编辑器属性面板是桩；iPad 零专项适配、折叠屏零设计。

**目标**：给「滤镜 / 美颜 / 裁剪 / 调节 / 贴纸 / 文字 / 素材库」等一切功能面板提供**一套管理框架**——面板开关有唯一状态机、容器按 size class 自适应、控件来自共享组件库——使 UIA-032/033、UIA-006、CAM-014 成为框架的纯消费方，不再各自发明面板。（编号备注 2026-10-07：原文的 UIA-015/016/017 为 RESEARCH-004 时代建议位，UIA-015~018 现归播放器线，编辑域落地为 UIA-032/033。）

**成功行为**：
- 新增一个参数面板 = 定义一个 `PanelRoute` case + 一段面板内容 View，容器/手势/重置/对比行为零新增代码；
- iPhone 与 iPad 上同一面板分别在 sheet 与右侧 Inspector 呈现，代码不分叉；
- 相机美颜面板（现存唯一真实效果面板）迁移进框架后行为无回归。

## 2. 关键架构事实（防跑偏）

1. **部署基线 iOS 16.0 / macOS 15.4**（ADR-0010）：`presentationDetents`（iOS 16+）可用；**`inspector()` 需 iOS 17+/macOS 14+，必须 `#available` 门控**，iOS 16 的 regular 宽度回退为 sheet；`presentationBackgroundInteraction`（16.4+）禁用。
2. **平台差异收敛在 EditorLayout**（ui-apple.md 硬约束 #6）：容器代码只进 `EditorLayout.swift` 及其子组件，业务视图不写条件编译。
3. **UI 不跨端共享**（ARCH-005）：SharedUI 只放组件库（控件、容器、路由状态机——「组件值与行为」），页面/布局各端各写。折叠屏布局属 Android UI 层，本文只交付设计契约（RESEARCH-005 §5.4）。
4. **相机域是 iOS 原生功能域**（ADR-0014）：相机特效走 `didSet→renderer` 快路径、无 Undo、录制中锁定（WYSIWYG）；**不得**为统一框架把相机参数改走 Command 或引入 core 依赖。
5. **编辑器面板参数必须走 Command**（UIA-006 验收既有约定；内核前置 MODEL-003/COLOR-003 未落地前，编辑器面板保持桩）。滑杆/拖拽**交互期间不提交命令，松手提交**（ADR-0012）。
6. **能力运行时查询**（红线 #3）：面板入口可见性/可用性由 `cq_query_capability()` 驱动，禁止编译期推断。
7. 现状三个真实呈现点（相机美颜 sheet、相机滤镜条、素材库区）与一个桩（属性面板）是迁移起点；自研相册浏览器（UIA-013）**本期不迁**（RESEARCH-005 §8.3）。

## 3. 范围（MVP）

**做**：
1. `PanelRoute` 面板路由状态机（相机域、编辑器域各一实例）；
2. `PanelHost` 自适应容器（sheet ⇄ inspector 门控切换）+ 四种呈现原型 API（sheet / inspector / inline / fullScreen）；
3. `PanelKit` 共享控件组件库：`ParamSlider`、`SwatchRow`、`ChipGroup`、`PanelSection`、`CropCanvas`（容器壳）；
4. 首批消费者迁移验证：相机美颜面板迁入 `PanelRoute + PanelHost + ParamSlider/PanelSection`；滤镜条入口状态并入 PanelRoute（视觉升级仍归 UIA-032）；
5. 面板入口能力门控接口（含美型占位行的置灰语义，为 CAM-013 预留）。

**不做**（防范围膨胀）：
- 不做编辑器滤镜/裁剪/调节**功能本体**（依赖 MODEL-003/COLOR-003/UIA-006）；
- 不动页面布局（iOS 抽屉化=UIA-033、macOS 惯例化=另行立项、滤镜缩略图视觉=UIA-032、时间线视觉=建议位已让位重开取新号）；
- 不迁移相册浏览器与素材库面板结构（UIA-033 处理）；
- 不引第三方 UI 库（红线 #10）；不做 Android/HarmonyOS 实现（仅契约文档）；不做浅色主题。

## 4. 技术方案

### 4.1 PanelRoute 状态机

```swift
/// 每域一个实例；唯一合法的面板开关入口
@MainActor
protocol PanelRouting: ObservableObject {
    var active: PanelID? { get }              // 同屏至多一个一级面板
    func open(_ id: PanelID)                  // 录制中/锁定态拒绝并给触觉反馈
    func close()
    var isLocked: Bool { get }                // 相机域=录制中；编辑域=导入/导出中
}
```

- `PanelID` 相机域：`beauty` / `sticker`（CAM-014 预留）；编辑器域：`filter` / `adjust` / `crop` / `sticker` / `text` / `properties` / `library`（UIA-006 起逐个启用）。
- 路由状态机为纯逻辑（无 UI 依赖），**可单测**；面板呈现一律 `active` 驱动，删除现有 `showBeautyPanel` 等散落布尔。
- 入口按钮的选中态（高亮）= `active == id`，解决现在美颜钮/滤镜条两套选中语义不一致的问题。

### 4.2 PanelHost 自适应容器

```swift
struct PanelHost<Content: View>: View {
    enum Placement { case adaptive, sheet }   // 编辑器用 adaptive；相机域固定 sheet
}
```

- `.adaptive`：compact → `.sheet` + `presentationDetents([.medium, .large])`；regular → iOS 17+/macOS 14+ 用 `inspector(isPresented:)`（trailing column，推开内容不遮预览），iOS 16 回退 sheet。macOS 直接走 inspector（基线 15.4 满足）。
- `.sheet`：一律 sheet（相机域沉浸式取景之上，面板应覆盖而非挤压画面；与系统相机惯例一致）。
- 四种呈现原型映射：sheet/inspector 由 `PanelHost` 提供；`inline`（滤镜条类常驻横滑）与 `fullScreen`（裁剪接管）为独立轻量容器 `InlinePanelBar` / `FullScreenPanel`，同受 PanelRoute 管理。
- 容器实现放 `Editor/EditorLayout.swift` 同目录（平台差异继续收敛），`#if os` 只出现在该收敛区。

### 4.3 PanelKit 组件库（SharedUI/Sources/SharedUI/PanelKit/）

| 组件 | 行为规范（来自 RESEARCH-005 §4.10 C） |
|---|---|
| `ParamSlider` | 双击滑杆圆点重置默认值；长按预览区对比原图/原参数（before/after）；拖动触觉反馈（刻度处 tick）；值气泡跟随；拖动中只回调 live 值、松手回调 commit 值（衔接 ADR-0012 两段式） |
| `SwatchRow` | 横滑缩略图卡（首版可用文字/纯色占位，UIA-032/033 换真图）+ 选中外描边 + 可选强度 ParamSlider 联动 |
| `ChipGroup` | 比例/模式 chips（单选、胶囊、选中描边） |
| `PanelSection` | 分组标题 + 折叠（Lightroom 组惯例）；组内参数行走 ParamSlider |
| `CropCanvas` | 全屏接管容器壳：角手柄、三分网格、比例 ChipGroup、旋转/取消/完成槽位（手势与几何本期只做容器约定，功能随 UIA-006） |

组件只依赖 Theme 令牌（UIA-014 产出；令牌未就绪前允许临时接现有 `Theme.swift` 常量，落地时统一替换）。

### 4.4 首批消费者迁移（验证框架）

1. **相机美颜面板**：`showBeautyPanel` 布尔 → `CameraPanelRoute.open(.beauty)`；面板内容重写为 `PanelSection + ParamSlider ×2`（磨皮/美白），美型禁用占位行改为能力门控置灰（`cq_query_capability`，无检测能力时置灰+「设备不支持」，CAM-013 落地后自动点亮）；`didSet→renderer` 快路径**不动**。
2. **相机滤镜条**：入口与选中态并入 `CameraPanelRoute`（呈现仍为 inline），为 CAM-014 贴纸条（同款 `SwatchRow`）立好先例。
3. **编辑器**：`PanelHost(.adaptive)` 容器与 `PanelKit` 就位并暴露给 EditorLayout；真实消费随 UIA-006/016/017。

### 4.5 四端布局分工

| 端 | 实现方 | 依据 |
|---|---|---|
| iPhone | 本框架 `.adaptive` compact 态 + inline/fullScreen 容器 | RESEARCH-005 §5.1 |
| iPad | 同一代码 `.adaptive` regular 态（inspector）+ Pencil/pointer/键盘走查项 | §5.2 |
| Mac | 本框架 inspector 态（UIA-017 接管页面与工具栏） | §5.3 |
| 折叠屏 | **仅交付契约**：RESEARCH-005 §5.4 三姿态表 + continuity 要求，写入 Android UI 立项输入 | §5.4 |

## 5. 非目标

见 §3「不做」。另明确：不改 `CameraViewModel` 参数语义、不改 Command/Session 架构、不做面板动效编排（仅系统默认过渡 + 微交互）、不做面板状态持久化恢复（inspector 呈现态由系统自动恢复，业务面板状态本期不持久化）。

## 6. 验收标准（可机器判定）

1. **编译门禁**：SharedUI `swift build` + `swift test`、iOS/macOS 工程编译在构建机通过（本机 P39 拒跑，按 UIA-011 先例延期非取消）；iOS 分支（compact/regular 两态）首次真实编译覆盖。
2. **单测**：`PanelRoute` 状态机单测覆盖——open/close/互斥（同屏至多一个）、`isLocked` 拒绝、`active` 高亮语义；`ParamSlider` 重置/commit 回调纯逻辑单测。既有 `CameraBeauty`/`CameraFilter` 单测不回归。
3. **grep 不变式**：`CameraView.swift` 内不再出现手写 `Slider(` 与 `showBeautyPanel` 布尔；全仓新增面板开关必须经 `PanelRouting`（code review 检查项）。
4. **行为不变式**：录制中美颜/滤镜/贴纸入口锁定语义与现状一致（disabled + WYSIWYG）；美颜参数 `didSet→renderer` 链路不回归（单测 + 走查）。
5. **走查清单**（双版本：iOS 16 回退态 + iOS 17+/26 态；设备：iPhone、iPad regular、Mac）：面板开/关/互斥、detents 拖拽、双击重置、长按对比、触觉、Dynamic Type 放大两档、深色下对比度、inspector 展开态系统恢复。
6. **性能**：面板展开/收起动画不掉帧（无主线程同步 IO/解码）；ParamSlider 拖动回调不触发主线程分配高峰（ Instruments 走查项）。

## 7. 开放问题

1. `CropCanvas` 的手势几何与时间线选中态联动（裁剪对象=选中片段）——UIA-006 Spec 细化，本期只交付容器壳。
2. 素材库/导入入口在 UIA-033 抽屉化后的去向（继承 RESEARCH-004 §8.3）；相册浏览器是否并入 PanelRoute 随 UIA-033 定。
3. `PanelHost(.adaptive)` regular 态是否直接作为 UIA-017 macOS Inspector 的实现载体（是则 UIA-017 写集减一）；倾向是，待 UIA-017 立项确认。
4. ParamSlider「长按对比」在相机域的对象是「原始帧」，需要 renderer 提供旁路快照——小 spike，随迁移做，超期则降级为面板内开关。
5. Theme 2.0 令牌与 PanelKit 的交接顺序（令牌未就绪先用旧常量，重复替换成本 [E] 一次性 <0.5 人日）。
