# reports/ — 周报层

> 立：2026-10-07（传哲拍板「搞个周报，周期总结项目进度、当前架构、项目介绍、下周目标」）。

## 规则

- 命名：`WEEKLY-<ISO 年>-W<周号>.md`（如 `WEEKLY-2026-W41.md`）。
- 出刊：**每周一期，集成机出**（与 ADR-0030 周度兜底门禁同轮）；开发机不写本目录。
- 固定结构：项目介绍 / 当前架构 / 本周进度 / 关键数字（本机实测）/ 下周目标 / 风险。
- 数字纪律照旧：实测才进表，估算标 [E]；门禁数字写具体（PASS=x/FAIL=y）。
- 归档：每周一期不覆盖；跨季审计沿文件名排序即可。
