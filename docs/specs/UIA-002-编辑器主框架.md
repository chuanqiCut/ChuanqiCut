# UIA-002：编辑器主框架（预览 + 时间线 + 属性面板）

> 版本：v1.0
> 日期：2026-10-01
> 依赖：BIND-002（已完成）
> 写集：`apps/apple/packages/SharedUI/`、`apps/apple/iOSApp/`、`apps/apple/MacApp/`、`apps/apple/project.yml`

## 1. 目标

搭建编辑器主界面的三区布局骨架，Mac 与 iOS 自适应。三个区域（预览、时间线、属性面板）先用桩视图，架构上预留后续任务（UIA-003/004/006）填充真实内容。

## 2. 三区布局

### macOS（宽屏）

```
┌──────────────────────────┬──────────┐
│                          │          │
│      Preview Zone        │ Property │
│      (弹性最大)          │  Panel   │
│                          │ (280pt)  │
├──────────────────────────┤          │
│    Timeline Zone         │          │
│    (220pt)               │          │
└──────────────────────────┴──────────┘
```

- 左侧 `HSplitView` 上 Preview 下 Timeline
- 右侧 PropertyPanel 固定 280pt 宽

### iOS（竖屏）

```
┌─────────────────────┐
│    Preview Zone      │
│    (60%)             │
├─────────────────────┤
│   Timeline Zone      │
│   (25%)              │
├─────────────────────┤
│  PropertyPanel Zone  │
│  (15%，可上拉展开)   │
└─────────────────────┘
```

- `VStack` + `GeometryReader` 按比例分配
- PropertyPanel 支持手势上拉展开至 50%

### iOS 横屏

与 macOS 布局同构（Preview+Timeline 左，PropertyPanel 右），但 PropertyPanel 可收起。

## 3. 架构约束

1. **UI 不得直接改模型**——一切变更走 `session.submit()` (Command)，铁律见 ARCH-005 §3
2. 三个 Zone 通过 `EditorViewModel`（`@Observable` / `@EnvironmentObject`）读取快照状态
3. 快照变更由 Session observer 推送到主线程，Zone 按版本号 diff 刷新
4. 平台差异用 `#if os(iOS)` / `#if os(macOS)` 收敛到 `AdaptiveStack` 工具，不散落在业务视图里
5. App 启动必须调用 `ChuanqiCut.markMainThread()`（见 CORE-008 约束）

## 4. EditorViewModel

```swift
@Observable final class EditorViewModel: ObservableObject {
    let session: Session
    var snapshot: Snapshot
    var lastChanges: [ChangeRecord]

    init()                           // 创建 Session，挂 observer
    func submit(_ name: StaticString, mutate: @escaping () -> Status) -> Status
}
```

- 持有唯一的 `ChuanqiCut.Session` 实例
- Observer 默认 dispatch 到 `DispatchQueue.main`
- `submit` 封装 `session.submit`，UI 层不直接碰 session

## 5. 桩视图规格

### PreviewZone

- 暗色背景（`Theme.previewBackground`）
- 中央显示 "Preview" 文字 + 快照版本号
- 预留 `MTKView` 嵌入位（UIA-003 将替换此桩）

### TimelineZone

- 暗色背景
- 顶部细线（播放头位置指示）
- 底部一条占位轨道（灰色条）
- 显示 "Timeline" 文字
- 预留自绘视图嵌入位（UIA-004 将替换此桩）

### PropertyPanelZone

- Inspector 风格：标题 + 占位参数行
- 暗色背景，分组标题线
- 显示 "Properties" 文字
- 预留参数绑定位（UIA-006 将替换此桩）
