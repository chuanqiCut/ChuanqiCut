## 12:5x CAM-017：真机首验四问题集中修复

**报告**（传哲）：磨皮闪屏 / 前摄竖屏横躺 / 拍照录制无效 / metallib 疑问。

**根因与处置**：
1. **录制无效 = 死锁（实证，P69）**：`pixelBufferPool` 在 startWriting 前是 nil
   （macOS 探针），旧代码在 setup 阶段预取池 + 池守卫排在 startSession 前 ⇒
   每帧必丢、writer 永不启动。修：时序重排 + 懒取池缓存 + 直配兜底 +
   markAsFinished 状态守卫 + 0 帧显式失败 + camera.recorder 遥测。
2. **前摄横躺**：前后摄传感器原生朝向不同，静态角度表按背摄推导。修：iOS 17+
   RotationCoordinator 逐传感器标定常量偏移（换镜头重标；位姿由主线程入口显式
   传入 —— iOS 26 SDK UIDevice 已 @MainActor，P71）。
3. **磨皮闪屏**：kernel 离屏 20 帧指纹唯一（算法层确定）⇒ 主嫌 = 设备上引擎
   间歇 nil → 逐帧视觉翻转。修：黏性回落（连续 3 次 nil 本会话停用引擎）+
   camera.beauty 遥测。若真机仍闪，抓日志定案（P60 族静默失败为次嫌）。
4. **拍照无效**：静态审查无定论（权限齐），capture→deliver→save 全链 os_log
   （camera.photo / camera.session），真机一次定位。

**验证**：BUILD SUCCEEDED 0 error / 改动文件 0 warning；模拟器冷启动无崩。
**遗留**：四项真机复验归传哲；pitfalls **P67 撞号再现**（MEDIA 线会话在我
