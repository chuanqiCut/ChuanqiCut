# SPEC-UIA-020：独立视频播放器

- **状态**：已确认（MVP 与 UIA-015 同日实施）
- **日期**：2026-10-05
- **上游**：[RESEARCH-006](../research/RESEARCH-006-独立播放器内核与交互调研.md) · [ADR-0022](../decisions/ADR-0022-独立播放器AVPlayer过渡与内核演进接缝.md)
- **任务**：[TASK-UIA-015](../tasks/TASK-UIA-015.md)（伞任务）

## 1. 背景与目标

ChuanqiCut 缺一个**独立播放器**：预览项目导出的成片、或播放用户选定的任意本地视频文件。要求体验对标一线产品（起播快、seek 跟手、变速可用、PiP/键盘/无障碍齐全）。

**用户价值与成功行为**：用户从首页（iOS）或独立窗口（macOS）选一个视频文件，能立即开始播放；能拖进度条（带缩略图预览）、倍速播放、双击快进快退、键盘操控（macOS）、画中画（iOS）、拔耳机自动暂停；VoiceOver 能完成播放控制。

## 2. 关键架构事实（防跑偏）

1. 自研预览线（`PlayerClock` + `PreviewPump` + RenderGraph）**无声**——PALA-030（AVAudioEngine 后端）在 BACKLOG 未实现，`core/src/audio/` 不存在。播"有声成片"眼下唯一路径是 AVPlayer。
2. 仓库先例：UI 域系统 API 豁免内核（ADR-0014 相机、ADR-0015 相册）。播放器 MVP 属同类。
3. 导出产物是普通 mp4（AVAssetWriter H.264+AAC），AVPlayer 直接可播；"成片播放"与"任意视频播放"在内核层无差别。
4. SharedUI 是 Swift 6 严格并发（tools 6.1，iOS 16 / macOS 15），P49：`#if canImport(UIKit)` 分支是 macOS 验证盲区，iOS 视角审查必须人工补。
5. CODESTYLE：用户可见文案中文；`os.Logger`（subsystem `com.chuanqi.cut`）；禁强解包；SharedUI 的 `public` 唯一判据 = 被 App target 消费。

## 3. 范围（MVP）

**内核**：`PlayerEngine` 协议接缝 + `AVPlayerEngine` 实现（详见 §4）。不动 `core/`、不动 C ABI、不动绑定层。

**UI（MVP 必做）**：

| 功能 | 交互细节 |
|---|---|
| 画面承载 | `AVPlayerLayer`（iOS UIView / macOS NSView 各一套 representable），适合/填充切换 |
| 控制层显隐 | 单击切换，播放中 4s 自动隐藏，交互重置；暂停时常显 |
| 播放/暂停 + 进度条 | 自绘进度条（填充轨道+圆点），拖动中只更新 UI 不 seek，松手零容差 seek；拖动中静音，松手恢复 |
| 时间码 | 左当前/右总时长；`mm:ss`，超 1h 进位 `h:mm:ss` |
| 双击快进快退 | 左半屏 -10s / 右半屏 +10s，中心气泡反馈，越界钳制到 [0, duration] |
| 上下滑调节（iOS） | 左半屏亮度（系统屏幕亮度）/ 右半屏音量（播放器音量），气泡反馈 |
| 缩略图预览 | 拖动气泡显示该秒缩略图（`AVAssetImageGenerator`，按秒去重 + LRU ≤120 张，失败静默降级为纯时间气泡） |
| 变速 | 菜单 0.5/0.75/1/1.25/1.5/2x，`audioTimePitchAlgorithm = .timeDomain` |
| 全屏（iOS） | 展开 = 忽略安全区 + 横屏视频请求横屏几何（`requestGeometryUpdate`）；收起还原 |
| 画中画（iOS） | `AVPictureInPictureController` 强持有 + 退后台自动进 + 播放器音量按钮 |
| 键盘（macOS） | 空格播放暂停；← → ±5s；，/. 逐帧步进（帧时长取 `nominalFrameRate`，未知回退 1/30s）；0-9 跳 0-90%；m 静音 |
| 中断与息屏 | 耳机拔出/来电 AVPlayer 默认自动暂停（不自写）；`isIdleTimerDisabled` 仅播放中为 true（iOS） |
| 无障碍 | 进度条 `.accessibilityAdjustableAction`（上下扫动 ±10s）+ 时间值播报；控制按钮全部中文 label |
| 错误呈现 | 打不开/解码失败显示中文错误横幅 + 重试，不静默黑屏 |
| 入口 | iOS 首页第三卡片"播放器"（fileImporter 选文件）；macOS 独立 `Window` 场景 |

**功能分档（后续迭代）**：

- **V1 应做**：~~长按倍速（2x 松手恢复+触觉）~~ ✅ 第二轮、~~A-B 循环~~ ✅（三态轮转+区间标记+区间外自动清除）、~~全片缩略图批量预生成~~ ✅（错峰预热 ≤24 桶）、~~倍速记忆~~ ✅（UserDefaults 注入）、~~音轨/字幕选择菜单~~ ✅ 第三轮（moreMenu 子菜单，nil=默认/关闭）、~~双击秒数可设置~~ ✅ 第三轮（5/10/15/30s 持久化，按钮图标随步长变化）；**剩余**：章节标记（AVAsset 章节 API 形状需构建机验证后做）。计划外增强：单片循环开关、换片（不退出播放器开新文件）、macOS 拖放打开。
- **V2 可做**：捏合缩放画面、HDR EDR 自绘（接 RenderGraph 后）、竖屏上下滑切集、快捷键自定义、macOS 画中画按钮、外挂字幕。

## 4. 技术方案

### 4.1 内核接缝（ADR-0022 核心）

```
PlayerScreen (public，App 消费)          ← 只依赖接缝
  └ PlayerViewModel (@MainActor)        ← 状态机 + 交互编排
      ├ engine: any PlayerEngine        ← 协议接缝（internal）
      │   └ AVPlayerEngine              ← MVP 实现（internal）
      └ VideoThumbnailLoader            ← 缩略图（LRU ≤120，按秒去重）
```

`PlayerEngine`（@MainActor 协议）：`load(url:) / play() / pause() / seek(to:precise:) / invalidate()` + 属性 `state / duration / currentTime / isPlaying / rate / volume / isMuted / videoSize` + 回调 `onTick(0.25s) / onStateChange / onEnded`。

- `AVPlayerEngine`：`automaticallyWaitsToMinimizeStalling = false`；`defaultRate` 承载倍速；KVO `item.status` 与 `AVPlayerItemDidPlayToEndTime` 均经 `Task { @MainActor }` 跳线程（手法同 AppEntry）。
- **画面 sink 与 AVPlayer 类型耦合是已知的 MVP 简化**：`PlayerScreen` 将引擎 `as? AVPlayerEngine` 取 `AVPlayer` 绑 `AVPlayerLayer`。未来 C++ 引擎落地时由其自带自绘 sink（RenderGraph blit），届时抽象 `PlayerSurfaceSink`（记入 ADR-0022 反转条件）。
- 时间口径：UI 边界用 `TimeInterval` 秒（同既有绑定层惯例）；红线 #4 的 RationalTime 属时间线模型，文件播放器无时间线，不引入。

### 4.2 缩略图

`VideoThumbnailLoader`：按秒取桶（bucket = floor(seconds)），命中 LRU 缓存直接返回；未命中按桶去重发起 `AVAssetImageGenerator.image(at:)`（async，tolerance ±1s，maximumSize 480）。缓存上界 120 张，超出按最久未用驱逐（内存上界 ≈120×270KB ≈ 32MB [E]，可接受）。

### 4.3 装配与入口

- iOS：`HomeView` 增第三入口 → `PlayerLauncherScreen()`（SharedUI，fileImporter 选视频 → fullScreen 语义内嵌播放）。
- macOS：`ChuanqiCutMacApp` 增 `Window("视频播放器", id: "player")` 场景，同一 Launcher。
- `ios/project.yml` info 增 `UIBackgroundModes: [audio]`（PiP/后台播放前置条件）。

## 5. 非目标（MVP 明确不做）

- 不动 `core/`、C ABI、绑定层、PAL——C++ 播放 session 是后续任务（ADR-0022 反转条件触发后立项）。
- MVP 不做流媒体/网络 URL 播放（仅本地文件）——**进阶版已解除**（用户拍板，[UIA-024](../tasks/TASK-UIA-024.md)，范围收敛为点播）；不做 MKV 等边缘容器承诺（AVPlayer 能播就播，不能播走错误横幅）。
- 不做 A-B 循环、字幕选择、长按倍速（V1）；不做捏合缩放、HDR 自绘（V2）。
- 不做 macOS 全屏按钮（系统窗口全屏可用）与 macOS 画中画按钮。
- 不引入任何第三方依赖（依赖治理零变更）。
- 不承诺与编辑器 RenderGraph 的画面一致性——那是 C++ session 阶段的目标。

## 6. 验收标准（可机器判定）

1. `swift test`（SharedUI）中 `PlayerTests` 全绿：拖动中不产生 seek、松手恰好一次零容差 seek 且恢复静音状态；skip 越界钳制；倍速透传；播完自动停止；时间码格式化（59.5s→"00:59"、3671s→"01:01:11"）；逐帧步进按 `frameDuration`。
2. 构建机 `xcodebuild`（iOSApp + MacApp target）0 error、项目代码 0 警告（含 Swift 6 严格并发）。
3. 门禁：`tools/ci/run_gate.sh` 的 SharedUI 步骤 PASS（数字待构建机回填）。
4. 行为清单（真机/构建机手测，逐项可观察）：选文件即起播；双击 ±10s 与气泡；拖动有缩略图气泡且松手落点与气泡时间一致；横屏视频全屏自动转横；倍速菜单生效且音调不飘；退后台自动进 PiP；耳机拔出暂停；macOS 空格/←→/，/. /0-9/m 全部生效；VoiceOver 可调进度。
5. 回归：`PlaybackTests`（UIA-010 编辑预览播放）与 `AlbumPickerTests` 不受影响。

## 7. 开放问题

1. 缩略图 LRU 上界 120 张在低端机的内存占用是否可接受——真机实测后回填 baselines（当前为估算 [E]）；预热错峰 50ms/张对低端机的瞬时压力待证。
2. iOS 端是否从相册（PhotoKit）选视频播放（与 UIA-013 自研相册浏览器复用）——MVP 先走文件选择器，V1 评估。
3. "最近导出"快捷入口（导出完成后一键预览成片）挂在导出流程哪一步——待导出界面任务（UIA-007）立项时对齐。
