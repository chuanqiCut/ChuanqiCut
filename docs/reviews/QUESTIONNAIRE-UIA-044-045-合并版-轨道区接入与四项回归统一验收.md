## 已知边界（不必当 bug 报）

- 转场 / 关键帧 / 画布 item / 蒙版**本轮不映射**（TimelineKit 有 UI，内核暂无对应命令）。
- macOS 与 iPad 之外仍是旧 SwiftUI 轨道区；TimelineKit 是 UIKit-only。
- 素材时长未透传 → 裁剪上限退化为片段自身源区间（不做假限制）。
- 内核若拒绝，会有一次瞬时"弹回"再落到真值（与旧轨道区同源）。
- TimelineKit 是**仓库外本地 Pod**（池 [20]，换机/CI 不可复现这条风险在册），
  本批按传哲裁定保持现状，不立 DEPS 卡。
