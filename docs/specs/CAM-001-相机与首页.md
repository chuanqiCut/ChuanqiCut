## 1. 目标

1. iOS App 加**首页**：两个入口「进入编辑」「进入相机」；编辑器 Session 改为进编辑器时惰性创建。
2. 新增**相机模块**：单摄实时预览（零拷贝进 Metal）、录制（复用 `IMediaMuxer`）、基础滤镜（LUT）。
3. **检测与特效底座**：中性观测结构（人脸框/关键点/姿态、宠物框/姿态）+ 特效链渲染骨架（LUT pass 先行，磨皮/美型 pass 预留）。
4. **双摄（前后同开）**：`AVCaptureMultiCamSession`，画中画合成预览、录制合成流；运行时能力查询，不支持降级单摄。**（v1.2 提前至当前执行；双摄开关必须是独立控件，前后翻转按钮永远只做单摄切换）**
5. **方向支持（v1.2 新增）**：预览/拍照/录制方向正确跟随界面方向（竖屏 + 左右横屏），渲染按 aspect-fill 铺满；预览不得上下颠倒。竖屏倒置（Upside Down）不支持，与系统相机一致。

## 2. 非目标（本期明确不做）

- macOS 相机（相机 UI 仅 iOS；Mac 端首页不改动，维持直进编辑器）。
- 精细美型（瘦脸/大眼/鼻翼）与 MediaPipe 468 点模型接入（依赖 AI-013 spike，本期只做**接口预留**）。
- 美体（瘦腰/长腿）——Phase C；本期仅保证观测结构含人体姿态扩展位。
- 宠物美化/美型——本期仅**识别**（猫狗框 + iOS 17+ 姿态门控），美化走贴纸锚定（复用贴纸系统）。
- 双视频轨分别录制（`IMediaMuxer` 维持单视频轨，双摄录**合成流**）。
- 实时特效应用到编辑器时间线预览（特效链先服务相机，时间线特效归 RENDER-001 既有规划）。
- Android / 鸿蒙实现（PAL 契约保证可移植，其他端返回"不支持"）。
- **（v1.2）竖屏倒置（Upside Down）方向**——与系统相机一致不支持。
- **（v1.2）录制中途旋转**——录制开始时锁定方向（与滤镜/美颜同语义），录制中旋转界面：预览 aspect-fill 中心裁切显示，录制流尺寸/方向不变；旋转跟拍需求另立任务再议。
- **（v1.2）双摄的分路录制**——维持单视频轨录合成流（v1.1 非目标沿用）。

## 4. 架构与红线对照

- **模块边界（ADR-0014）**：相机采集→特效→录制 = **iOS 原生功能域**（Swift + AVFoundation + Vision/ARKit + Core Image/Metal，落 `apps/apple/ios/iOSApp/`），不经 PAL/C ABI；**编辑器内核维持 C++ 跨端**，录制产物经既有 `cq_session` 导入路径进时间线。
- **扬长清单**：ARKit 人脸网格（1220 顶点，TrueDepth）/ Vision 76 点、AVDepthData 真实景深、Center Stage、Core Image 滤镜、MetalFX 升采样（A17 Pro+）、MultiCamSession 硬件时间戳、CoreML(ANE) 模型直转（不走 tflite 管线）。
- **红线边界（ADR-0014 §3）**：#1 对相机页会话/预览/录制编排豁免（UI 功能域），进时间线仍走 Command；#6 管 SDK 渲染资产，相机页特效 shader 属 App 层资产；#3 直接查系统能力（`isMultiCamSupported` / `@available`），不加内核枚举。
- **时间**：采集/录制 PTS 用 CMSampleBuffer 硬件时钟；与时间线交接处转 `RationalTime`（120000 网格，ADR-0009）。
- **线程**：采集回调专用串行队列；渲染在 MTKView 渲染线程；主线程零阻塞（红线 #8）。帧策略 latest-wins。
- **录制**：所见即所得（Core Image 处理后画面）；`AVAssetWriter` 视频轨 + AAC 音频轨（`AVCaptureAudioDataOutput` PCM sampleBuffer 直喂 `AVAssetWriterInput`）。

## 7. 非功能约束

- 崩溃/失败路径诚实暴露（工厂 NULL、Status 透传），不伪造成功。
- 权限拒绝（用户不给相机权限）：UI 明确提示 + 引导，不闪退。
- 低功耗/后台：App 进后台自动停止采集；录制中进后台用 `beginBackgroundTask` 收尾。
- 日志：采集/渲染/录制各环节埋点（ADR-0010 §6 要求，真机排障依赖）。

## 9. 跨端影响

- Android（P1）：相机模块**零复用**（ADR-0014 代价，Phase 3 按 CameraX + ML Kit/自训模型重写，独立任务群）；编辑器内核不受影响。
- 鸿蒙（P2）：同上，无动作。
- Swift UI：相机页与首页不进 MacApp target；SharedUI 新增代码须保持 `#if os(iOS)` 隔离或平台无关。
