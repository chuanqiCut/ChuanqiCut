## 二、拍摄模块介绍

**是什么**：ChuanqiCut 的相机/拍摄功能域——实时预览、实时美颜/滤镜、拍照、录制，产物一键进时间线编辑。按 ADR-0014/0021 定为 **iOS 原生功能域**（Swift + AVFoundation + Vision + Core Image/Metal），不经 PAL/C ABI；编辑器内核维持 C++ 跨端，录制产物经既有 `cq_session` 导入路径进时间线。

**分期**（SPEC-CAM-001 v1.2，传哲拍板）：
- **A 期（已完成）**：首页双入口、单摄预览（MTKView + Core Image）、滤镜预设、录制（AVAssetWriter H.264+AAC）存相册/进编辑器、权限路径。
- **B 期（进行中，约 70%）**：Vision 检测桥、Metal 磨皮、方向全支持、美颜质量修复、人脸区域化——已完成；剩余：双摄（CAM-021）、美型（CAM-013）、贴纸锚定（CAM-014）。
- **C 期（未开工）**：MetalFX 升采样、景深人像、宠物美化、美体。

**关键拍板**：双摄从 C 期提前至 B 期；横竖屏全支持（预览/拍照/录制方向跟随）；UI 栈 SwiftUI + MTKView 混合，不引 UIKit 生态库。

## 三、架构介绍

**三段分工**（单写者线程模型，主线程零阻塞）：

```
采集  CameraManager      AVCaptureSession（会话配置/启停全在 sessionQueue 串行）
  ├─ videoQueue 视频帧 → 帧槽 latest-wins（不排队，杜绝延迟累积）
  └─ audioQueue 音频包 → CameraRecorder.appendAudio
渲染  CameraPreviewRenderer（MTKViewDelegate 连续绘制）
      CVPixelBuffer → CIImage → 处理链 → 自建中间纹理 → 显式 UV 渲染 pass → drawable
录制  CameraRecorder（videoQueue 内 AVAssetWriter + PixelBufferAdaptor）
拍照  capturePhoto → 同一条 process 链 → 存相册
```

**三个关键设计决策**：

1. **预览渲染终态**（踩坑换来的）：Core Image 不能直写 MTKView 的 framebufferOnly drawable（静默黑屏），也不能 blit（Metal 规范封死，校验层必炸）。终态为 **CI → 自建中间纹理（ShaderWrite|ShaderRead）→ 显式渲染 pass → drawable**，drawable 恢复 framebufferOnly=true 拿回显示优化；aspect-fill 逐帧重算采样窗，转屏零重建成本。同形态方案已在编辑器播放器验证。
2. **WYSIWYG 三路一致**：预览、拍照、录制走**同一条处理链（美颜 → 滤镜）**，录制开始时锁定 preset+美颜参数，保证"所见即所得"。
3. **方向补偿体系**：采集按 UIInterfaceOrientation 映射 `videoRotationAngle`，前摄传感器横装有 270° 常量补偿（两代真机现象反推定案）；iOS 16 旧 API 走语义方向且横屏名互换（Apple 文档原文依据）；渲染层带符号 vScale 做 CI 行序补偿。录制中锁定方向（与系统相机一致）。

**美颜引擎（B 期核心）**：
- Metal 双边滤波磨皮 kernel 替换 A 期 CI 高斯近似，宿主实测 **9.85ms@1080p（s=0.5），较 CI 高斯 19.12ms 快约 2×**；真机 ≤8ms 阈值待实测。
- 人脸区域化：Vision 人脸关键点 → One-Euro 帧间平滑 → 羽化蒙版 → 磨皮/美白经蒙版混合，背景不受影响；无脸/检测失败直通，三态（nil/[]/非空）纯函数单测锁定。
- 色彩空间修正：CIContext 显式 workingColorSpace=gamma sRGB，与 kernel 定标域一致，消除真机磨皮闪烁；引擎闭包带**黏性回落**（连续 3 次失败停用引擎走 CI 兜底，防逐帧视觉翻转）。
- 录制路径 buffer 显式标记色彩空间，预览=录制颜色。

**工程化（本周新增）**：`ChuanqiCutCamera` 独立 iOS 专属 Pod——契约层（滤镜/美颜参数/引擎注入点，4 文件）+ 实现（采集/渲染/录制/ViewModel/Detection/Effects）+ 4 个测试文件；与编辑器经 `EditorEntryInjector` 横向解耦；metallib 编译管线留壳工程（Pod 静态库 script_phase 产物进不了 App bundle 的假绿案底）。
